Overview

AllWorth is a full-stack personal finance app that brings checking, savings, credit, investment and loan accounts into one net worth view, with spending analytics, budgets, subscription detection and an AI assistant.

It runs on iOS, Android and the web from a single React Native (Expo) codebase and talks to a FastAPI and PostgreSQL backend.

Highlights

  • Per-user data isolation: Firebase Auth tokens are verified on the server, and every query is scoped to the signed-in user, not just checked at the auth boundary.
  • A constrained AI assistant: Claude cannot query the database. It can only call seven read-only tools (net worth, balances, transactions, spending by category, period comparison, subscriptions, large transactions), each scoped to the user.
  • Bank linking with Plaid Sandbox: access tokens are encrypted at rest, and disconnecting a bank soft-deletes its accounts so history is kept but stale balances never appear in net worth, budgets or the assistant.
  • Subscription detection: recurring charges are found when a merchant repeats across months, and duplicate charges are flagged.
  • One codebase, three platforms: web-only pieces live in .web.tsx files, and the web build is a static export deployed on Vercel against the same API.

The API is on Render's free tier, so the first request after inactivity can take 30-50 seconds to wake up.

Tech Stack

React Native + Expo

One TypeScript codebase for iOS, Android and web, with Expo Router navigation

TypeScript

Typed client, API layer and TanStack Query hooks

FastAPI

REST API with per-user query scoping on every endpoint

PostgreSQL

SQLAlchemy models and Alembic migrations

Firebase Auth

Sign-in on the client, ID tokens verified on the server

Plaid Sandbox

Bank linking, with access tokens encrypted at rest

Claude API

Assistant limited to seven read-only, per-user tools

Render + Vercel

API and database on Render, static web build on Vercel

Pytest

Tests for AI tools, auth, budgets, chat and spending math
